Seven lockups. Each in color, white, and black.
Each in SVG, EPS, and PNG (1x, 2x, 3x, and 3000px wide, transparent).

+ Primary                 Full lockup, outlined LABS panels

+ Stacked                 Condensed lockup, outlined LABS panels

Use EPS for print. EPS files are CMYK.
Use PNG only where vector is not an option.

Clear space: one LABS panel width on all sides.
